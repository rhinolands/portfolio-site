01 / Flagship

One enforcement point for every agent action.

You cannot reliably detect every hostile instruction an agent reads. You can decide what it is allowed to do. That is the job of an enforcement point.

aegis TypeScript + Postgres · tested · CI · Apache-2.0

An open-source agent-governance gateway. It sits between AI agents and the tools, peer agents and models they call, and decides every action before it runs. Built for regulated environments where routing agent traffic through a SaaS is a non-starter.

Deny by default

OPA/Rego policy compiled to WASM and evaluated in-process. An unknown tool, peer or model is denied without a rule needing to exist.

Credentials the agent never holds

The gateway injects a scoped backend credential only after policy allows the call. A stolen agent key cannot reach the backend token.

Tamper-evident audit

Every allow and every deny is recorded in a hash chain. An edited, deleted or reordered record is caught on verification.

Fail closed

Unknown caller, policy error or upstream failure returns a denial plus an audit record. No path turns an error into an allow.

Four governed planes: agent ingress · agent-to-agent delegation · MCP tool egress · LLM upstream

Case study: threat-modeling my own gatewayaegis, open source · the full write-up is public in the README
Context
aegis injects a scoped backend credential into each agent call only after policy allows it, so the agent never holds the secret. The finding below was caught in review inside the pull request, before the code reached the main branch. It never shipped in a release.
The finding
The first cut of the planes let the caller name the upstream URL in the request body. An authenticated agent with one allowlisted tool could point the gateway at a server it controlled and receive the injected credential. The agent never held the secret. It made the gateway deliver it anywhere, which is the same thing.
Root cause
The trust boundary covered the credential but not where the credential goes. The destination carries authority too. The same class of bug appeared once more on the LLM plane: a caller-supplied payload overrode the policy-approved model, so the audit named the wrong model and cost was metered at the wrong rate.
The fix
Destinations now resolve server-side from the operator-registered agent and target record. The caller names a tool, peer or model, the gateway decides where it goes, and denies when nothing is registered. Redirects are rejected. Trusted values are applied last. Both fixes are locked by regression tests that were verified to fail when the fix is reverted.
Lesson
Least privilege covers every input that carries authority: the secret, where it is sent, and which model runs.

05 / How I work

Four rules I hold every system to.

Verified claims

Two independent sources and a math sanity check before any number ships.

Staged rollout

Fixture, canary, wave, soak. A fix never goes straight to a big batch.

Reuse first

Extend proven infrastructure. Never a parallel rebuild.

Enforced, then trusted

Anything a system must never do belongs in an enforced control that holds even when the model misbehaves.
